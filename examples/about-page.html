CardManager

Um kanban board minimalista e eficiente para gerenciar suas tarefas

Sobre o Projeto

CardManager é uma aplicação de gerenciamento de tarefas baseada no conceito de Kanban. Permite organizar tarefas em colunas com funcionalidades de drag-and-drop.

Drag & Drop intuitivo
Interface responsiva
Multi-idioma
Design minimalista

Motivação

O objetivo é criar um editor de Markdown utilizando Svelte + Tauri, combinando a reatividade do Svelte com a eficiência do Rust. Este projeto serviu como base para entender padrões e o fluxo de desenvolvimento em Svelte 5, especialmente as novas Runes, antes de partir para a implementação em Rust e Tauri.

Tecnologias

Svelte 5 Framework principal com Runes
TypeScript Tipagem estática
svelte-dnd-action Drag & Drop
Vite Dev server rápido
svelte-i18n Internacionalização
